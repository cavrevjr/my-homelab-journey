# 🏠 HomeLab Journey

> Building a production-inspired homelab from scratch while documenting every decision, challenge and lesson learned.

---

## 🎯 About

Welcome to my HomeLab!

This repository documents my journey of building a modern homelab using open-source technologies. The goal is not only to self-host services, but also to understand the engineering decisions behind them and document the entire learning process.

Rather than simply installing software, this project focuses on building a solid foundation in Linux, Docker, networking, automation and cybersecurity.

---

## 🚀 Goals

* Learn Linux system administration
* Master Docker and containerized applications
* Understand networking fundamentals
* Explore self-hosted services
* Study monitoring and observability
* Build cybersecurity and infrastructure skills
* Document everything along the way

## 📖 Engineering Journal

Every milestone of this project is documented in the Engineering Journal.

Each sprint includes:

* Objectives
* Decisions made
* Challenges encountered
* Lessons learned
* Next steps

The idea is to document not only **what** was built, but also **why** it was built that way.

## 🎯 Long-Term Vision

The objective of this project is to evolve from a simple virtual machine into a complete production-inspired homelab capable of hosting infrastructure, monitoring, automation and security services.

This repository will grow together with the homelab, following the principle:

> **Start simple. Learn deeply. Improve continuously.**
